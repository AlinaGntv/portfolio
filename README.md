### Парсинг & Лидогенерация

#### Парсер лидов через Яндекс Карты
- **Тип:** Конвейер парсинга из 8 модулей (CLI + GUI)
- **Описание:** Парсер, который собирает организации в Яндекс Картах по нише и городу и формирует Excel-файл лидов для ручной квалификации. Полный конвейер: генерация сетки запросов → поиск → скролл выдачи → разбор карточек → дедупликация → геофильтр → экспорт.
- **Архитектура:**
  - **Точки входа:** `main.py` (CLI: `--query "где поесть" --city "Пушкино" [--headless --limit N --num-queries N --radius N]`) и `gui.py` (окно на tkinter: ниша, город, кол-во запросов, радиус, кнопка «начать сбор»)
  - `grid.generate_queries` — строит сетку запросов: при `count=1` — «ниша город», при `count>1` — базовый запрос + районы города из справочника `grid.DISTRICTS`
  - `workflow.build_search_url` — сборка `yandex.ru/maps/?text=запрос город` с защитой от дубля города
  - Playwright открывает Chromium с постоянным профилем (`output/chrome-profile`), маскируясь под обычного пользователя (UA, ru-RU, Москва, окно 1440×900); `--headless` — без окна
  - `scraper.collect_org_list` — скроллит панель выдачи (гребками + колесо мыши), собирает ссылки `yandex.ru/maps/org/<id>` из DOM; останавливается после 10 прокруток без новых карточек (`STALE_SCROLLS_STOP`)
  - Контроль троттлинга: если результатов меньше 15 — пауза 15 сек и повтор
  - `scraper.scrape_card` — по карточке организации извлекает: название, категорию, адрес, телефон, сайт, рейтинг, отзывы, часы работы, координаты (из `ll=` в URL)
  - `dedup.deduplicate` — удаляет дубликаты по `org_id`, сливает более полные записи, статистика total/unique/removed
  - `geo.filter_by_radius` — фильтр по радиусу от центра города (формула гаверсинуса, только при `--radius`); записи без координат сохраняются
  - `exporter.export_safe` — пишет Excel `output/leads_<дата>.xlsx`; если файл открыт — автоувеличивает имя с временем; красивая шапка, автофильтр, автоширина, закреплённая строка, выпадающие списки для ручной квалификации (статус лида, причина, написала, ответ)
  - `models.py` — модель `Organization` (org_id, имя, адрес, телефон, сайт, рейтинг, координаты и т.д.)
  - Тесты: `test_dedup.py` — юнит-тесты дедупликации
- **Стек:** Python, Playwright, tkinter, OpenPyXL, Yandex Maps, Web scraping
- **Ссылка:** [github.com/AlinaGntv/leads-parser-ya-maps](https://github.com/AlinaGntv/leads-parser-ya-maps.git)
